# 운전과 학습

[가이드 목차](README.md) · [English](operation.en.md)

## 운전 모드와 프리셋

| 모드 | 동작 |
| --- | --- |
| OFF | 자동 난방 제어를 끄고 난방 정지를 요청합니다. 실제 기기 OFF 확인도 필요합니다. |
| HEAT | 목표온도, 시작·정지 편차와 최소 ON/OFF 시간으로 제어합니다. |
| AUTO | 기본 온도 제어에 학습 기반 예측 시작·정지를 추가합니다. |

HOME/AWAY는 목표온도를 바꾸는 프리셋입니다. 일반 난방 학습을 쌓는 동안에는 안정적인 목표온도와 재실 조건으로 운전하세요. AWAY 회차는 공통 학습에서 제외됩니다. 목표온도·모드·프리셋 변경이나 외부 조작으로 회차가 중단되면 학습에서 제외될 수 있습니다.

## 초기 학습과 예측 제어

설치 또는 학습 리셋 후 별도의 강제 학습 절차 없이 평소 운전으로 데이터를 모읍니다. 가동시간 기반 예측 OFF에는 실제 가동시간과 정지 후 확정 최고온도가 있는 유효 난방 사이클이 최소 **3회** 필요합니다. 켠 횟수나 스위치를 조작한 횟수를 세는 것이 아닙니다.

3회가 쌓여도 모든 외기·가동시간 조건에서 예측이 가능한 것은 아닙니다. 현재 조건에 맞는 근거가 부족하면 기본 온도 제어를 사용합니다. 예측 ON은 냉각과 난방 반응 지연 학습으로 별도 판단합니다.

- **예측 ON**을 켜면 예상 냉각과 측정된 난방 반응 지연을 고려해 미리 가동할 수 있습니다. 최소 OFF 시간과 안전 조건은 계속 적용됩니다.
- 시작을 결정할 때 실내온도가 **목표온도−난방 시작 편차 이하**이면 일반 난방을 우선합니다. 그보다 높은 온도에서 예측 조건으로 조기 시작할 때만 예측 ON으로 분류합니다. 목표 23°C·편차 0.5°C라면 22.5°C 이하는 일반 난방, 22.6°C 이상은 예측 조건 충족 시 예측 ON입니다. 외출에서 재실로 전환하거나 목표온도를 바꿀 때도 같은 기준을 사용합니다.
- **예측 OFF**는 가동시간 모델로 초기 정지를 예약합니다. 하이브리드 모델의 근거가 충분하면 현재 온도와 예상 잔열 최고온도로 정지 시점을 다시 판단합니다. 초기 예약만 보고 반드시 그 시각에 정지한다고 단정하지 마세요.
- **난방 정지 후 잔열 관측** 중에는 온도가 계속 오를 수 있습니다. 이 구간이 최고온도와 실제 예측 오차를 확인하는 데 필요합니다.

### 조기 정지를 허용하는 범위

실측 가동시간 하한은 학습 통과 10회 전까지 최대 20%, 이후 기본 최대 10%까지 낮출 수 있습니다. 이후 외기·예측 오차 보정으로 필요한 가동시간이 줄면 별도로 최대 5%를 추가 허용합니다. 계산된 가동시간에서 이 비율을 무조건 빼는 기능은 아닙니다.

최종 가동시간은 사용자 최소 ON 시간, 최근 유효 10회 가동시간 평균의 60%, 기존 목표 미달 보정 하한을 지킵니다. 평균에는 학습 통과·제어 학습 보류 없음 조건을 만족한 회차를 사용합니다. 운전 시작 전 평균의 60% 미만인 회차는 평균에서만 제외하며, 해당 회차의 예측 학습 여부를 일괄 변경하지 않습니다. 평균은 외기 구간을 나누지 않고 저장하며 재시작과 상세 기록 정리 후에도 유지됩니다.

## 최고점 확정과 관측 종료

최고온도보다 **0.1°C 이상 낮은 실제 센서 보고**가 나온 뒤, 다음 실제 보고가 **직전 보고보다 0.1°C 이상 추가 하락**하면 최고점을 확정합니다. 예를 들어 `23.9 → 23.8 → 23.7°C`에서 23.9°C가 확정됩니다. 낮은 값이 반복되거나 시간만 지나는 것으로는 확정하지 않습니다. 난방 반응이 실제로 관측되어야 합니다.

확정 시각과 최고점 시각은 다릅니다. 최고점 시각은 해당 최고온도가 마지막으로 실제 보고된 시각입니다.

| OFF 시점의 근거 | 관측 종료 방식 |
| --- | --- |
| 최근 최대 10회 비교의 평균 절대오차가 0.5°C 초과이거나 필요한 정보가 없음 | 최고점 관측 시간 한도를 적용합니다. 기본 6시간이며 예측 운전 설정에서 1~12시간으로 조정합니다. |
| 평균 절대오차가 0.5°C 이하이고, 당시 예상 최고온도와 일출 정보가 있음 | 위 시간 한도를 적용하지 않습니다. 일출 이후 실제 온도가 당시 예상 최고온도보다 0.5°C를 초과하면 일출 종료로 관측을 끝내고 학습에서 제외합니다. |

종료 방식은 실제 OFF 시점의 근거로 선택합니다. 수동 중단, 센서 오류, 최고점 전 재상승 등 다른 관측 종료 조건도 별도로 적용됩니다.

## 일출 절약

**예측 운전 설정 → 일출 절약**을 켜고 시작·종료 시각을 각각 저장합니다. 지정 시간에는 AUTO 예측 정지 목표가 **목표온도 + 상한 허용 편차**에서 **목표온도**로 내려갑니다.

Home Assistant 현지 시각을 사용하고 자정을 넘는 구간도 지원합니다. 두 시각이 같으면 적용하지 않습니다. 일출 절약 회차는 일반 회차와 섞어 공통 학습하지 않고 기록으로 남깁니다. 지정 시간표를 쓰는 일출 절약과, 실제 일출 이후 예측 최고온도 초과로 관측을 끝내는 일출 종료는 서로 다른 기능입니다.

## 대시보드 읽기

| 화면 | 확인할 내용 |
| --- | --- |
| 대시보드 | 선택한 방의 현재 온도, 운전 상태, 난방 정보와 최근 운전 결과 |
| 예측 분석 | 초기 정지 예약, 현재 판단 모델, 예상·실제 최고온도와 오차 비교 |
| 학습 분석 | 회차별 승인·제외 사유, 최근·장기 학습 근거, 관측 데이터 |

Heating과 Cooling은 같은 운전에서도 별도 기록입니다. 진행 중인 회차는 종료 후 목록에 나타납니다. 표본 수나 모델 내부 신뢰도가 실제 예측 정확도와 같은 의미는 아니므로, 저장된 예상·실측 최고온도 비교도 함께 확인하세요.
