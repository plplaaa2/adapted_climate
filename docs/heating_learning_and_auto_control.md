# 난방 학습 및 AUTO ON/OFF 제어 흐름

현재 구현의 완결 사이클 학습과 AUTO 판단 순서를 나타냅니다. 센서·히터 상태는 Home Assistant에 보고된 값을 기준으로 합니다.

## 난방 학습 흐름

OFF·HEAT·AUTO 모두 확인된 히터 전환과 실제 실내온도 보고를 관측합니다. 아래 사이클은 히터를 끈 시점이 아니라 OFF 후 최고온도를 지나 하강이 확인될 때 완결됩니다.

```mermaid
flowchart TD
    A["확인된 히터 전환과 실내온도 보고"] --> B{"유효한 입력과 연속된 보고?"}
    B -- "아니오" --> X["진행 중 사이클 폐기"]
    B -- "예" --> C["OFF→ON: 시작 시각·온도 기록"]
    C --> D["ON 중: 온도 상승곡선과 반응 지연 관측"]
    D --> E["ON→OFF: 가동시간·정지 온도·기울기<br/>가능하면 곡률 기록"]
    E --> F["OFF 후: 잔열 상승과 최고온도 추적"]
    F --> G{"최고점 후 15분 경과,<br/>냉각 기울기 ≤ -0.1°C/h?"}
    G -- "아니오" --> F
    G -- "예" --> H["완결 사이클 생성"]
    H --> I["지표별 유효 범위·이상치 검사"]
    I --> J["유효 지표 EWMA 갱신·신뢰도 계산"]
    I --> K{"잔열 표본과 응답곡선 유효?"}
    K -- "예" --> L["ON 및 OFF→최고점 곡선 정규화·보관<br/>최대 24개"]
    K -- "아니오" --> M["곡선 학습 건너뜀"]
    J --> N["학습 모델 저장"]
    L --> N
    M --> N
```

센서 오류·보고 공백·재시작 또는 제어 중 예상하지 못한 스위치 전환으로 끊긴 사이클은 완결 표본으로 학습하지 않습니다. 난방 반응 지연·가열률·잔열 상승·최고점 지연은 각각 검증하며, 평균 가열률은 진단값으로 유지합니다. 현재 모델은 에어컨 운전 상태를 입력받지 않아 보일러 단독 운전과 에어컨 병행 운전의 곡선을 분리하지 않습니다.

## AUTO ON/OFF 적용 흐름

기본 제어기가 현재 온도, 오류, 시작 시 OFF 확인, 히스테리시스와 최소 ON/OFF 시간을 먼저 평가합니다. AUTO는 허용된 기본 결정에 학습값을 적용합니다.

```mermaid
flowchart TD
    A["온도 보고·히터 전환·타이머"] --> B["안전 검사와 기본 히스테리시스 결정"]
    B --> C{"운전 모드"}
    C -- "OFF" --> Z["자동 ON 명령 없음; 외부 사이클 관측"]
    C -- "HEAT" --> R["기본 결정 사용"]
    C -- "AUTO" --> D{"안전 정지·시작 대기?"}
    D -- "예" --> R
    D -- "아니오" --> E{"확인된 히터 상태"}
    E -- "OFF" --> F{"최소 OFF 완료 + 유효한 냉각 기울기·반응 지연으로<br/>반응 시점 온도 ≤ 목표?"}
    F -- "예" --> PON["예측 ON"]
    F -- "아니오" --> G{"기본 ON 요구 + 잔열 관측 중?"}
    G -- "예" --> H{"정지 시 온도 + 신뢰도 반영 잔열 ≥<br/>목표 + AUTO 정지 편차?<br/>최고점 예상 시각 이전?"}
    H -- "예" --> WAIT["잔열 재가동 대기"]
    H -- "아니오" --> R
    G -- "아니오" --> R
    E -- "ON" --> I{"기본 결정이 계속 가열하고<br/>최소 ON 시간 완료?"}
    I -- "아니오" --> R
    I -- "예" --> J{"비슷한 완결 곡선 ≥ 3개,<br/>유사도 충분?"}
    J -- "예" --> K["현재 가동시간·상승 형태·기울기·곡률로<br/>OFF 후 추가 상승량 추정"]
    J -- "아니오" --> L{"유효한 잔열 상승 EWMA?"}
    K --> M{"현재 온도 + 신뢰도 반영 추가 상승량 ≥<br/>목표 + AUTO 정지 편차?"}
    L -- "예" --> M
    L -- "아니오" --> R
    M -- "예" --> POFF["예측 OFF"]
    M -- "아니오" --> R
    PON --> Q["히터 명령·상태 확인·다음 평가 예약"]
    WAIT --> Q
    POFF --> Q
    R --> Q
```

학습값이 없으면 AUTO도 기본 히스테리시스 결정을 사용합니다. 예측 ON은 최근 냉각 기울기와 학습된 반응 지연을 사용하고, 예측 OFF는 곡선이 충분하면 곡선 기반 잔열 추정을 우선합니다. 잔열 재가동 대기는 완결 곡선이 아닌 기존 잔열·최고점 지연 집계값을 사용합니다. AUTO의 기본 정지 경계는 목표온도 + 0.5°C이며 옵션에서 조정할 수 있습니다.
