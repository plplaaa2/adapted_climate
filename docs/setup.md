# 초기 설정

[가이드 목차](README.md) · [English](setup.en.md) · 다음: [운전과 학습](operation.md)

## 1. 설치 전에 준비하기

Home Assistant에서 아래 엔티티가 정상 동작하는지 먼저 확인하세요. 엔티티 ID는 개발자 도구의 상태 화면에서 확인할 수 있습니다.

| 엔티티 | 확인할 내용 |
| --- | --- |
| 실내온도 센서 | 해당 공간의 실제 온도를 숫자로 보고하며 `device_class: temperature`, 단위 `°C` 또는 `°F`를 제공해야 합니다. `unknown`·`unavailable` 상태에서는 설정할 수 없습니다. |
| 난방 스위치 | 스위치형에서 사용합니다. `on`·`off` 상태를 보고하고 실제 난방 요청을 켜고 끌 수 있어야 합니다. |
| 기존 온도조절기 | Climate형에서 사용합니다. 난방 모드, 단일 목표온도 설정, `hvac_action`의 실제 난방 상태 보고가 필요합니다. |
| 실외온도 센서 | 선택 사항입니다. 실내 센서와 같은 온도 형식을 지원해야 하며 외기별 학습과 예측 보정에 사용합니다. |

같은 난방 기기를 다른 통합 설정이나 방에 중복 등록할 수 없습니다. 기존 자동화가 같은 스위치나 온도조절기를 조작하는지도 확인하세요. 통합의 명령과 다른 외부 조작은 오류 잠금이나 학습 제외를 유발할 수 있습니다.

온도 센서는 제어하려는 공간을 대표하는 위치에 두고, 운전 도중 위치를 자주 바꾸지 않는 편이 좋습니다. 센서 위치나 난방 배관 구성이 달라지면 기존 학습과 실제 반응의 관계도 달라질 수 있습니다.

## 2. 제어 방식 선택하기

통합 추가 화면에서 **Adaptive Floor Heating Climate**를 선택한 뒤 다음 중 하나를 선택합니다.

| 방식 | 구성 방법 |
| --- | --- |
| 스위치형 → 단독/각방 개별 제어 | 난방 스위치 한 개와 실내 센서 한 개를 연결합니다. 여러 방을 독립 제어하려면 방마다 별도로 추가합니다. |
| 스위치형 → 멀티룸(통합) | 방 수를 2~32개로 입력하고 공용 실내 센서 하나와 각 방의 스위치를 차례로 선택합니다. 하나의 Climate와 학습 모델로 모든 스위치를 함께 제어합니다. |
| Climate형 | 기존 온도조절기 한 대와 실내 센서를 선택하고, OFF 요청용 하한과 ON 요청용 상한을 입력합니다. 방별 독립 제어는 방마다 별도로 추가합니다. |

통합 멀티룸은 모든 스위치가 같은 상태로 확인되어야 합니다. 일부만 켜지거나 상태가 확인되지 않으면 그룹 정지와 오류 처리가 적용됩니다.

### Climate형의 하한·상한

기본 하한은 **18°C**, 상한은 **30°C**입니다. 두 값은 이 통합의 실내 목표온도와 다릅니다. 난방 요청 시 기존 온도조절기에 상한을 보내고, 정지 요청 시 하한을 보냅니다. 해당 온도조절기가 지원하는 범위 안에서 설정해야 합니다.

예를 들어 이 통합의 목표온도가 23°C여도 실제 온도조절기에는 ON 요청 시 30°C, OFF 요청 시 18°C가 표시될 수 있습니다. 하한보다 온도조절기의 자체 측정온도가 낮으면 OFF 요청 후에도 난방할 수 있으므로 실제 `hvac_action`을 확인하세요. 학습은 요청 시각이 아닌 온도조절기가 보고한 실제 난방 시작·정지를 사용합니다.

## 3. 난방 설정 입력하기

아래 기본값과 단위는 현재 설정 화면 기준입니다. **최대 연속 가동시간**은 분 단위로, 다른 운전·보호 시간은 초 단위로 입력합니다.

| 항목 | 기본값 | 의미 |
| --- | --- | --- |
| 난방 시작 편차 | 0.5°C | 기본 제어에서 실내온도가 목표온도보다 이 값 이상 낮으면 난방 시작을 판단합니다. |
| AUTO 정지 편차 | 0.5°C | AUTO 기본 정지 기준과 예측 정지 목표의 상한 허용 편차입니다. |
| HEAT 정지 편차 | 0.0°C | HEAT에서 목표온도보다 얼마나 높아졌을 때 정지할지 정합니다. |
| 최소 난방 시간 | 900초, 15분 | 정상 온도 제어에서 너무 짧은 가동을 막는 최소 ON 시간입니다. |
| 최대 연속 가동시간 | 60분 | 실제 난방 ON부터 한 회차의 가동시간을 제한합니다. 60~180분에서 설정할 수 있습니다. |
| 난방기 통신 끊김 학습 유예 시간 | 60초 | 학습 제외 판정을 보류할 시간입니다. 0~300초에서 설정할 수 있으며, 0초면 즉시 제외합니다. |
| 기본 최소 정지 시간 | 1,800초, 30분 | 실제 최소 OFF 시간의 기본값입니다. 설정 화면에서는 1,800~3,600초를 입력할 수 있습니다. |
| 학습 관측 온도 보고 간격 한도 | 900초, 15분 | 온도 관측 관련 시간 설정이며 실외 센서 값의 유효성 판단에도 사용됩니다. 실내온도의 숫자가 그대로라는 이유만으로 난방 정지 시간을 정하는 값은 아닙니다. |
| 재실 프리셋 온도 | 23°C | HOME 선택 시 적용할 목표온도입니다. |
| 외출 프리셋 온도 | 18°C | AWAY 선택 시 적용할 목표온도입니다. |

실제 최소 OFF 시간은 **설정한 최소 정지 시간과 직전 연속 가동시간의 2배 중 큰 값**입니다. 예를 들어 40분 가동한 뒤에는 기본값이 30분이어도 재가동 대기가 80분이 될 수 있습니다. 안전 정지나 명시적인 OFF 명령은 일반적인 최소 ON 대기보다 우선합니다.

목표온도 23°C와 기본 편차를 사용하면 기본 제어의 시작 기준은 22.5°C, HEAT 정지 기준은 23°C, AUTO 기본 정지 기준은 23.5°C입니다. AUTO 예측이 가능하면 잔열 상승을 고려해 이 온도에 도달하기 전에 정지할 수 있습니다.

난방 온도 편차와 운전 시간·보호를 별도 화면에서 설정한 뒤 재실·외출 온도를 입력합니다. 선택 센서 화면에서는 외기 보정용 온도 센서와 일출 학습용 `weather.*` 엔티티를 지정할 수 있습니다. 마지막 **설정 확인** 화면에서 입력한 난방 설정과 선택 센서 요약을 검토한 뒤 완료합니다.

## 4. 첫 운전 확인하기

1. 새로 생성된 Climate의 초기 모드가 `OFF`이고, 연결한 실내 센서의 온도가 표시되는지 확인합니다.
2. 먼저 `HEAT`로 기본 제어와 실제 난방 상태 보고가 연결되는지 확인합니다. 목표온도·현재온도와 최소 OFF 대기 조건을 함께 보세요.
3. 스위치형은 실제 스위치 상태, Climate형은 기존 온도조절기의 `hvac_action`이 난방 요청에 따라 바뀌는지 확인합니다.
4. 사이드바 **바닥난방**에서 해당 방을 선택하고 제어 상태, 오류, 현재 난방 정보를 확인합니다.
5. 기본 동작을 확인한 뒤 `AUTO`를 선택합니다. 초기에는 학습 근거가 부족해 기본 온도 제어를 사용할 수 있습니다.

학습을 만들기 위해 목표온도를 반복 변경하거나 기기를 강제로 켰다 끌 필요는 없습니다. 평소 조건으로 운전하고, 난방 정지 후 잔열 최고점과 냉각 관측이 끝날 시간을 주세요. 초기 학습의 조건은 [운전과 학습](operation.md)을 참고하세요.
