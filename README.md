# Adaptive Floor Heating Climate

[![HACS](https://img.shields.io/badge/HACS-Custom-41BDF5.svg?style=for-the-badge)](https://github.com/hacs/integration)
![version](https://img.shields.io/badge/version-v0.1.0-blue.svg?style=for-the-badge)
[![Ko-fi](https://img.shields.io/badge/Ko--fi-Support%20Me-F16061.svg?style=for-the-badge&logo=ko-fi)](https://ko-fi.com/plplaaa2)

Home Assistant용 학습형 바닥난방 Climate 커스텀 통합입니다. 실내 온도 센서와 난방 스위치를 연결해 기본 온도 제어를 제공하며, 운전 이력을 학습해 AUTO 모드에서 난방 시작과 정지를 보조합니다.

> [!IMPORTANT]
> **실험용:** 이 통합 구성요소는 실험용입니다.
> 
> 동작에 대한 보장을 하지 않으며 설치 및 사용에 관한 책임은 사용자에게 있습니다.
>



## 주요 기능

- **Climate 엔티티 제공**
  - 운전 모드: `OFF`, `HEAT`, `AUTO`
  - 목표 온도: 18~30°C
  - 프리셋: `HOME`, `AWAY`

- **기본 난방 제어**
  - 설정 온도와 시작/정지 편차에 따른 히스테리시스 제어
  - 최소 ON/OFF 시간 적용
  - 온도 센서 오류, 스위치 상태 불명, 과열, 외부 스위치 조작 시 안전 정지 및 오류 잠금
  - 스위치 명령 후 Home Assistant가 보고한 실제 상태 전환을 확인

- **학습 기반 AUTO 제어**
  - 난방 반응 지연, 가열률, 난방 OFF 후 잔열 상승, 최고 온도 도달 지연을 학습
  - 5분 단위 난방·냉각 커브와 최근/장기 학습값을 저장
  - 학습 데이터가 충분할 때 예상 잔열을 고려해 조기 난방 시작 또는 난방 정지를 수행
  - 데이터가 부족하거나 예측에 실패하면 안전하게 기본 히스테리시스 제어로 동작

- **예측 ON 스위치**
  - 켜짐: 학습된 냉각 커브와 히터 ON 후 온도 상승까지의 전체 반응 지연을 반영합니다. 외기 센서가 설정되어 있고 현재 외기 구간에 반응 지연 전체를 덮는 표본이 있으면 해당 커브를 사용합니다.
  - `현재 실내온도 + 반응 지연 동안 예상 냉각량`이 `목표온도 − 난방 시작 편차` 이하이면 미리 가동합니다.
  - 꺼짐 또는 연속 냉각 학습 근거 부족 시 기본 시작 기준을 사용하며, 최소 정지시간과 안전 조건을 유지합니다.
  - 기존 저장값 `eco`는 꺼짐, `balanced`와 `comfort`는 켜짐으로 읽으며 과거 학습 기록은 유지합니다. 기존 예측 운전 선택 엔티티는 예측 ON 스위치로 교체됩니다.
  - 예측 OFF는 이 스위치와 별개로 학습 근거가 충분할 때 사용합니다.
  - 최고점 이후 히터가 꺼진 동안 최대 3시간까지 5분 단위로 냉각을 관측합니다. 학습 분석의 냉각 커브에서 외기 구간별 온도 변화량과 표본 수를 확인할 수 있습니다.
  - 외기별 냉각은 구간별 최근 학습값(Current)과 안정적으로 반복된 장기 학습값(Long-term)을 저장합니다. 장기 학습값이 충분하면 이를 기준으로 최근 관측을 반영합니다.
  - 예측 ON은 현재 정지 구간에서 확인한 최고점과 관측된 난방 반응 지연을 사용합니다. 외기별 학습이 반응 지연 전체를 덮고 추가 하락이 예상되지 않으면 기본 시작 기준을 따릅니다.

- **이번 난방 예측과 결과 비교**
  - 예측 분석 상단에서 지금 정지하면 예상되는 최고온도, 예상 총 가동시간, 예정 종료를 확인합니다. 계산 근거와 검증 정보는 펼쳐 볼 수 있으며, 예측이 없으면 대기 이유를 안내합니다.
  - 가동시간 모델의 예상 총 가동시간과 예정 종료를 표시합니다. 합산 예측처럼 종료 시각을 예약하지 않는 모델은 해당 없음으로 표시합니다.
  - OFF 당시 예상 Peak는 도달 시각을 가정하지 않는 수평 기준선으로 표시합니다. Peak 확정 후 실제 최고온도 및 실제−예상 차이를 비교합니다.
  - 실제 Peak 확정 시 당시 학습 근거로 계산한 냉각 예측을 최고점의 시각·온도에 고정하여 저장합니다. 연속된 5분 학습 구간까지만 표시하며, 재시작 후에도 당시 예측을 복원합니다.
  - 화면 맨 아래에 자체 학습 DB의 최근 30일 이력 중 난방 최대 5회를 표시합니다. 회차별 예상·실제 최고온도와 오차를 비교하고, 펼치면 시작·정지 시각과 실제 가동시간을 확인합니다. 과거에 저장하지 않은 예측값은 기록 없음으로 표시하며 재계산하지 않습니다.
  - 회차별 요약·진단과 개별 학습 표본은 종료 시각 기준 30일, 원시 5분 관측값은 7일 보관합니다. 통합 시작 시와 이후 하루 한 번 오래된 이력을 정리합니다. Current·Long-term 학습 요약과 누적 예측 정확도는 별도로 보관합니다. 이력과 누적 정확도 조회에는 Recorder가 필요하지 않습니다.

- **단독 및 통합 멀티룸 지원**
  - 단독: 히터 스위치 1개와 실내 온도 센서 1개
  - 통합 멀티룸: 공용 실내 온도 센서 1개와 여러 히터 스위치를 하나의 Climate로 제어
  - 멀티룸은 모든 스위치가 같은 상태를 확인해야 난방 상태를 확정합니다. 상태가 섞이거나 알 수 없으면 전체 OFF를 요청하고 안전 잠금 처리합니다.

- **관측과 진단**
  - 난방 중 온도 변화와 OFF 후 최고 온도를 관측
  - Climate 속성에서 제어 상태, 오류, 확인된 히터 상태, 명령 대기 상태, 예측 결과를 확인
  - 학습 상태와 관측 상태를 진단 Sensor로 제공
  - 별도 초기 학습 절차 없이 일반 난방 운전으로 학습하며, 커브 학습·온도 관측·예측 상태의 3개 센서를 제공합니다.
  - Home Assistant 사이드바의 **바닥난방** 패널에서 운전 상태, 학습·예측 결과와 커브 이력을 확인

## 설치

개발 환경에서는 다음 폴더를 Home Assistant 설정 디렉터리에 복사 또는 링크합니다.

```text
custom_components/adaptive_floor_heating/
```

그 후 Home Assistant를 재시작하고 통합을 추가합니다.

마켓 플레이스에서 사용자 지정 저장소로 설치할 경우 저장소 주소를 추가하고 유형을 **통합(Integration)**으로 선택합니다.

- 저장소: <https://github.com/plplaaa2/adapted_climate>

## 설정 방법

Home Assistant에서 **설정 → 기기 및 서비스 → 통합 추가**로 이동한 뒤
`Adaptive Floor Heating Climate`를 선택합니다.

1. 제어 방식을 선택합니다.
   - 단독 제어
   - 통합 멀티룸 제어
2. 히터 스위치와 실내 온도 센서를 선택합니다.
3. 시작/정지 편차, 최소 ON/OFF 시간, HOME/AWAY 온도를 설정합니다.
4. 필요하면 외기 조건별 가동시간 예측과 예측 OFF의 외기 보정에 사용할 실외 온도 센서를 추가합니다.
5. 확인 화면에서 설정을 저장합니다.

설정을 저장해도 기본 운전 모드는 `OFF`입니다. Climate 엔티티에서 `HEAT` 또는 `AUTO`를 명시적으로 선택해 운전을 시작하세요.

## 운전 모드

| 모드 | 동작 |
| --- | --- |
| `OFF` | 자동 제어를 하지 않습니다. 외부에서 동작한 난방 사이클은 관측할 수 있습니다. |
| `HEAT` | 목표 온도와 히스테리시스에 따라 기본 난방 제어를 수행합니다. |
| `AUTO` | 기본 제어에 학습 기반 예측 ON/OFF를 추가합니다. |

`HOME`과 `AWAY` 프리셋은 목표 온도만 변경하며, 운전 모드를 자동으로 바꾸지 않습니다.

## 안전 동작

다음 상황에서는 난방을 중지하거나 시작을 보류합니다.

- 실내 온도 센서값이 유효하지 않음
- 히터 스위치 상태를 확인할 수 없음
- 실내 온도가 과열 기준 이상
- 스위치 명령 확인 실패
- 활성 제어 중 외부에서 히터 스위치가 변경됨

오류 잠금 상태는 원인이 해소되고 히터 OFF 및 최소 OFF 시간이 확인된 뒤, 사용자가 `HEAT` 또는 `AUTO`를 다시 선택해야 해제됩니다.

## 저장과 재시작

목표 온도, 운전 모드, 프리셋, 예측 운전 정책과 학습된 모델은 설정 항목별로 저장됩니다. 재시작 후 진행 중이던 온도 이력과 미완결 관측 사이클은 버리며, 현재 센서와 히터 상태를 다시 확인한 뒤 안전 조건을 만족할 때만 제어를 재개합니다.

**설정 → 기기 및 서비스 → 바닥난방 기기 → 구성**에서 **학습 리셋**을 누르면 해당 기기의 학습 커브, 잔열·가동시간 학습, 실패 기록과 자체 예측 비교·정확도 이력이 초기화됩니다. 통합 멀티룸은 해당 Climate가 공유하는 학습을 초기화합니다. 히터 OFF가 확인되고 대기 중인 스위치 명령이 없을 때 사용할 수 있습니다. 목표 온도, 운전 모드, 프리셋, 연결 설정과 HA Recorder 이력은 유지됩니다.
사이드바의 **학습 분석** 탭에서도 선택한 기기와 초기화 범위를 확인한 뒤 같은 **학습 리셋**을 실행할 수 있습니다.


## 참고 사항

- 이 통합이 확인하는 히터 상태는 Home Assistant 스위치 상태입니다. 실제 버너 점화, 물 순환, 열 전달 또는 가스 사용량을 직접 측정하지 않습니다.
- 학습 기반 예측은 충분한 정상 난방 사이클이 쌓인 뒤에만 적용됩니다.
- 실제 난방 환경에서 센서 위치, 보고 주기, 바닥 구조, 외기 조건에 따라 학습 품질과 예측 결과가 달라질 수 있습니다.

## 대시보드와 예측

대시보드에서 학습 현황과 예측 결과를 확인하고, 예측 분석에서 계산 근거와 완료된 관측 결과를 살펴볼 수 있습니다.

AUTO의 예측 OFF는 충분한 정상 학습 기록이 있으면 잔열과 외기·난방 반응 등을 반영합니다. 근거가 부족하면 다른 예측 경로 또는 기본 온도 제어를 사용합니다.

HA 기기의 **OFF 모델 선택** 또는 대시보드의 왼쪽 셀렉터에서 AUTO 정지 모델을 선택합니다. 기본인 **가동시간 모델**은 회차당 종료 시각을 한 번 예약합니다. **합산 잔열 모델**은 유사 운전의 잔열 평균을 사용하고, **가동합산 모델**은 가동시간별 잔열 곡선을 보간합니다. 두 잔열 모델은 외기·난방 반응·오차를 보정하며 학습 범위 안에서 유사 기록이 3회 이상일 때 정지 판단에 사용합니다. 선택한 모델의 근거가 부족하면 기본 온도 제어로 운전합니다.

가동합산과 가동시간 모델은 최근 회차의 근거가 부족할 때, 해당 온도나 가동시간을 양쪽에서 뒷받침하는 Long-term 구간이 있으면 장기 학습으로 정지 판단을 이어갑니다. 이때 구간별 실측 가동시간과 최고점 또는 잔열 상승량을 사용합니다. 장기 근거도 부족하면 기본 온도 제어를 따릅니다. 예측 분석에는 장기 학습을 사용한 정지 예측을 표시하며, **가동합산 동일 회차 비교**에서는 최근 회차 모델과 구간 요약 후보의 예측이 모두 있었던 회차의 평균 절대 오차를 볼 수 있습니다.

난방 중 모델을 바꾸면 다음 회차부터 적용합니다. 실제 난방 관측과 목표 미달 학습은 모델 간에 공유하며, 예측 오차 보정과 정확도는 모델별로 저장합니다. 오른쪽의 **예측 ON** 스위치는 난방 시작만 설정합니다. 최소 가동시간 중에도 계산 가능한 예측은 표시하지만 예측 정지는 보류합니다. 정지 후에는 마지막 정지 당시의 예상 최고온도를 표시합니다.

예측 분석에서는 선택한 OFF 모델, 이번 회차의 OFF 모델, 마지막 정지 예측 모델을 구분해서 보여줍니다. 가동시간 모델은 총 가동시간과 예약을, 잔열 모델은 예상 최고온도와 잔열 보정 내역을 표시합니다.

정지 당시 목표 최고온도와 실제 최고온도를 비교해 학습 가중치를 정합니다. 목표 미달 폭이 클수록 가중치가 낮아지고, 비슷한 가동시간의 관측은 함께 평균합니다. 예측 정지 후 실제 온도 보고에서 목표에 못 미친 상태로 같은 목표의 자동 재가동이 확인되면, 이후 유사한 조건에서 조기 정지를 보류하는 근거로 사용합니다. 목표온도가 기록되지 않은 기존 회차는 기존 관측값을 보존하고 달성 여부는 미확인으로 표시합니다. 기존 학습 DB는 통합 시작 시 자동으로 마이그레이션합니다.

실내 온도 변화율 그래프는 5분 간격의 온도 변화를 표시하며, 예측 제어에 사용하는 변화율과는 별도로 계산합니다.

학습 분석은 종류별 학습 반영·제외 횟수, 최근·장기 학습 커브, 사이클 기록 순으로 표시합니다. 기록을 선택하면 판정과 핵심 관측값을 먼저 확인하고, 품질 검사·학습 반영 전후·원본 5분 데이터는 펼쳐 볼 수 있습니다. 현재 모델의 장기 학습 근거와 과거 기록 당시의 근거는 별도로 표시하며, 커브 점수는 예측 정확도를 뜻하지 않습니다. 모바일에서는 선택한 기록 바로 아래에 상세 정보가 표시됩니다.
